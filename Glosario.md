# Actividad Final de Unidad. Glosario de conceptos

### 1. Algoritmo 
#### - Descripción: 
Serie de instrucciones o pasos que suceden secuencialmente para realizar una acción concreta. 
#### - Ejemplo: 
- Encender el ordenador 
- Asegurarnos de que la impresora tiene papel y cartuchos de tinta 
- Encender la impresora 
- Abrir el documento que queremos imprimir 
- Seleccionar la opción de “Imprimir” el documento 
- Elegir las características de impresión como número de páginas o color 
- Seleccionar la impresora que vamos a utilizar 
- Imprimir el documento

---
### 2. Programa
#### - Descripción: 
Conjunto de instrucciones codificadas que un dispositivo electrónico puede ejecutar para realizar una tarea especifica.
#### - Ejemplo: 
Navegadores web, editores o apps moviles

---
### 3. Código fuente
#### - Descripción:
Es un conjunto de instrucciones en lenguaje de programación que le indican a la computadora que es lo que debe de hacer. El código fuente es la base de cualquier aplicación, pagina web, sistema operativo, etc.
#### - Ejemplo: 
este código fuente escrito usando Python: 
Nombre = "Ana"
  print("Hola, " + nombre + "! Bienvenido al código fuente.")

---
### 4. Lenguaje de programación
#### - Descripción: 
Los lenguajes de programación son unas herramientas que proporcionan la estructura y las reglas para construir un software. Estos permiten a los programadores comunicarse con la computadora.
#### - Ejemplo: 
 JavaScript. Python, C++, SQL, etc.
 
---
### 5. Sintaxis
#### - Descripción:
Es el conjunto de reglas que definen el como se escribe un código para que una computadora pueda interpretarlo correctamente.
#### - Ejemplo: 
Como ejemplo tenemos a Python el cual usa sintaxis, limpia y utiliza espacios para ordenar código

---
### 6. Variable
#### - Descripción:
Es un contenedor en la memoria física o virtual de un computadora donde se almacenan distintos tipos de datos durante la ejecución de un programa.
#### - Ejemplo: 
Enteros (int), decimales (float), cadenas de texto (string), etc.

---
### 7. Constante
#### - Descripción:
Es un valor fijo que un programa no puede modificar mientras se esta ejecutando.
#### - Ejemplo: 
Valores matemáticos (como pi), configuraciones del sistema, datos fijos, valores booleanos, etc.

---
### 8. Tipo de dato
#### - Descripción:
Se refiere a el formato de almacenamiento de datos que define las características de esos datos y su rango de valores.
#### - Ejemplo:
El valor 42 el cual es un tipo de dato numérico entero, mientras que "México" es un tipo de dato de texto (cadena de caracteres).

---
### 9. Operador
#### - Descripción:
Es un símbolo o palabra reservada que representa una operación a realizar entre uno o más operandos.
#### - Ejemplo:
En la expresión a + b, el operador + indica una suma entre los operandos a y b
### 10. Expresión 
#### - Descripción:
Es la manera en que expresamos algo sobre el estado de un objeto.
#### - Ejemplo:
En la línea resultado = (10 + 5) * 2, toda la porción (10 + 5) * 2 es una expresión que da como resultado 30.

---
### 11. Condicional 
#### - Descripción:
Son unas estructuras que permiten elegirla ejecución de alguna cosa u otra, se podría decir que es el “Si y no” condicional que usamos en alguna frase.
#### - Ejemplo:
if (edad >= 18) { print("Eres mayor de edad")

---
### 12. Bucle 
#### - Descripción:
Es una estructura de código que se ejecuta una y otra vez (iteración) hasta que se cumple una condición.
#### - Ejemplo:
**for i in range**(n)

### 14. Parámetro 
#### - Descripción:
Son los nombres de valores pasados a una función mediante una llamada a función. Los parámetros son los valores que espera recibir la función.
#### - Ejemplo:
direct-declarator ( parameter-type-list ) 

---
### 15. Argumento 
#### - Descripción:
Es la información o valor concreto que se le pasa a una función cuando es invocada, permitiendo que esta personalice su comportamiento con datos específicos.
#### - Ejemplo:
En la llamada calcularTotal(100, 0.16), los valores 100 y 0.16 son los argumentos enviados para procesar el precio y el impuesto.
